Assess fit and overlap.

1. From DESCRIPTION (biocViews, Imports/Depends), the vignette and the R code: does the package use or extend Bioconductor infrastructure (classes, annotation, data containers)? Does it interoperate with existing workflows? Cite the code.
2. Name the closest existing Bioconductor (and CRAN) packages you know of for the same task, say how this one differs, and whether the submitter addressed this. Say clearly when you are unsure a package exists or what it does; never invent package names.
3. Give a recommendation for the reviewer (fits / fits with changes / better suited to CRAN) with reasons. This is advice to the reviewer, not a decision.
